# Submission checklist

- [ ] Your code is in the repository, and the README explains how to run it.
- [ ] `results.csv` has one row per experiment, with all the required columns.
- [ ] There are prediction files in `outputs/predictions/` for every experiment.
- [ ] The figures are in `outputs/figures/`.
- [ ] Every part of `analysis.md` is complete.
- [ ] All the numbers come from full runs on the complete test set, not from debug runs.
- [ ] No model weights, LoRA adapters, datasets, caches, or tokens are committed.
- [ ] Gradescope is linked to the correct repository and commit.
